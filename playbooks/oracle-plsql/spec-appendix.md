# 仕様章立ての追補（oracle-plsql）

ISO/IEC/IEEE 29148 準拠の章立て（GP-8）に対する、このスタック固有の追補。
汎用テンプレート（`specs/*/_template.md`）の節では表現しきれない要素だけを扱う。

- **対象スタック**: Oracle の PL/SQL（パッケージ・プロシージャ・関数・トリガー・オブジェクト型）と、PL/SQL が読み書きする表

## 追加すべき節（カテゴリ別）

| カテゴリ | 追加する節 | 理由（このスタックで必要になるもの） | 密度の判定基準 |
|---------|----------|--------------------------------|--------------|
| api | 公開 API の一覧（パッケージ.サブプログラム） | 仕様に宣言された公開サブプログラムが外部契約。オーバーロードは別々の API（DP-oracle-plsql-1） | サブプログラム 1 つにつき引数（IN / OUT / IN OUT・型・既定値）・戻り値・権限（AUTHID）・GRANT の先 |
| api | 公開の範囲 | `GRANT EXECUTE` の先のロール・スキーマ、同義語（`PUBLIC SYNONYM`）が呼べる範囲を決める（`list-grants`） | パッケージ 1 つにつき GRANT の先と同義語 |
| behavior | サブプログラムの処理の流れ | 引数の検査 → 表の読み書き → 例外の処理 → COMMIT / ROLLBACK の順序と条件が仕様 | サブプログラム 1 つにつき分岐ごとの表の操作と出口 |
| behavior | トランザクションの制御と例外 | COMMIT の位置・自律型トランザクション・捕まえる例外とエラー番号が、失敗時に何が残るかを決める（DP-oracle-plsql-4） | サブプログラム 1 つにつき COMMIT の有無・例外とエラー番号・`WHEN OTHERS` の扱い |
| behavior | トリガー | 事象・行 / 文の単位・INSTEAD OF の対象・トリガーの中の副作用（別の表の更新・自律型の COMMIT）が、アプリから見えない振る舞いを作る | トリガー 1 つにつき事象・単位・条件（WHEN）・更新する表 |
| behavior | ジョブ | DBMS_SCHEDULER / DBMS_JOB のジョブが、時刻で処理を起動する（`list-jobs`） | ジョブ 1 つにつき実行内容・間隔・失敗時の扱い |
| modules | パッケージの責務と状態 | パッケージ本体の変数（セッションごとの状態）・初期化部・非公開のサブプログラムが、呼び出しの順序に依存する振る舞いを作る | パッケージ 1 つにつき状態の変数・初期化・非公開のサブプログラムの役割 |
| modules | オブジェクト型 | 型の継承（UNDER）・NOT INSTANTIABLE・MEMBER / STATIC / CONSTRUCTOR のメソッドが、呼び出しの多態を作る | 型 1 つにつき親の型・メソッドの全数・抽象かどうか |
| data | サブプログラム × 表 × 操作（CRUD） | 表の操作が PL/SQL の静的 SQL・動的 SQL・トリガーに分かれる（`list-crud` / `list-dynamic`） | サブプログラム 1 つにつき参照・更新する全表と操作 |
| data | 表とビューの定義 | 列・制約・索引・シーケンス・同義語・初期データ（導入スクリプトの INSERT）が DDL のスクリプトにある | 表 1 つにつき列・主キー・外部キー・索引・初期データの有無 |

## 記述方式の指定

同じ対象を複数の書き方で書くと横断突合ができなくなるため、方式を固定する。

- **API は `パッケージ.サブプログラム` で書き、綴りは `idents-subprogram` の出力に合わせる**（`G-IDENT` は大小を区別して突合する）。オーバーロードは引数の並びを添えて区別する。
- **表は物理名で書き、綴りは `idents-table` の出力に合わせる。** 同じ名前の表が別のスキーマにあるときはスキーマを添える（`OE.customers`）。
- **引用は `path:line` で書く**（`hr_code.sql:77`）。パッケージは仕様と本体の両方を引く。
- **呼び出しの関係は `list-calls` の辺で書き、コードグラフのエッジと一致させる。**

## このスタックで静的読解が効かない箇所（SB-6 の具体化）

- **動的 SQL**: `EXECUTE IMMEDIATE l_sql`・`DBMS_SQL`・`OPEN c FOR l_sql` は、文字列を組み立てる側を読まないと表と操作が決まらない（`list-dynamic` の「(式)」）。
- **ラップされたユニット**: `wrapped` の本体は読めない（`list-wrapped`）。仕様の宣言だけを書き、振る舞いは UNKNOWN に起票する。
- **同義語と DB リンク**: 同義語（`CREATE SYNONYM`）の先は解くが、DB リンク（`表@リンク`）の先は別の DB で、ソースに無い。
- **セッションの状態**: パッケージの変数・`DBMS_SESSION.SET_CONTEXT`・`SYS_CONTEXT` の値は、呼び出しの順序とセッションで決まる。
- **DB にだけある定義**: 手で足した表・索引・権限は、ソースのスクリプトに無い。DB のデータディクショナリの書き出しと突き合わせる。
- **エディションと条件付きコンパイル**: `$IF ... $END`（条件付きコンパイル）・エディションで、同じソースから別の実装が選ばれる。
