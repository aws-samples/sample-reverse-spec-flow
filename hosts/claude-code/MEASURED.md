## 追補: 検証官の隔離（2.1.305 / 2026-10-21）

`spec-verifier` と `verifier-guard.sh`（`agents/`・`hooks/`）の設計根拠。設計の全体は `docs/designs/verifier-isolation.md`。
測り方は、フィクスチャの各ファイルに一意のトークンを埋め、検証官の出力とセッション記録に現れるかを見るもの。
**現れたトークンは漏れの証拠になるが、現れなかったことは漏れていない証明にならない**（判定の多くはモデルの自己申告に基づく）。
**回数は項目ごとに記録していない**（1 回以上。判定は揺れなかった）。再測定するときは回数を残すこと。
